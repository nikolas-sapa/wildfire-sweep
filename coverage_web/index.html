CAPTURED STUDY / SPATIAL COVERAGE

Coverage Atlas

A read-only atlas of one captured study. Spatial coverage is the fraction of equal-area cell centers an initially idle drone network reaches within 900 seconds.

Spatial coverage
Cell-center reach fraction on an equal-area model grid, not a season success rate or ignition-risk estimate.
Idle grid
Every case is a single alert against an initially idle network. No queueing or fleet contention.
Captured only
Stored cells, counts, and fractions shown exactly as received. The browser recomputes nothing.
Non-field limits
Synthetic model output, not field validated. Not a forecast, detector result, geographic map, or flight-control system.
